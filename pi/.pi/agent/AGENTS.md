# Personal workflow preferences

- Use `wt` (worktrunk) rather than raw `git worktree` commands when listing, creating, switching, removing, or merging Git worktrees. Check `wt --help` or the relevant subcommand help before using an unfamiliar operation.

- Never create a GitHub issue solely to satisfy a pull request template, checklist, or repository convention. When asked to create a pull request and no suitable issue already exists, create the pull request without an issue link and leave the corresponding checklist item unchecked. Only create a GitHub issue when I explicitly ask for one.
